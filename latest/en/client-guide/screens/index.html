    Screen overview

    Screen Purpose
    Home Pick the opponent (AI) and start a match. Entry point to Settings, How to Play, and Quit.
    Settings Change language, battle pop-up duration, and board log mode.
    How to Play Rules summary and the effect text of every card.
    Duel The game itself: board, hand, left panel (card detail), and log.
    Online Online play lobby (create / join a room).

    On the Home screen, move between OPPONENT / SETTINGS / HOW TO PLAY / QUIT with Up/Down, and press Left/Right on the OPPONENT row to change the AI. Press Enter to confirm (OPPONENT starts the match). Quit via the QUIT item (there is no dedicated quit key).

    Reading the board

    • The board is an accordion: only the cursor's row is shown full-size (other rows are minimized).
    • The opponent's magic/trap zone is shown too.
    • The left panel shows the detail (attack power, status, materials, effect) of the card under the cursor.
    • Attack power is shown like A9. While boosted by an effect the number turns green (this is the value actually used in combat). Battle popups also show effective values like SK(5) vs H5(3).
    • Monsters with materials stacked underneath show a count badge like x2 (the left panel shows Mat x2).
    • The staircase activation menu shows which cards from your hand will be spent (e.g. Stair 3 (S3 S4 S5)).
    • While REV is shown next to the turn indicator, Revolution is active (the attack/defence order is reversed).

    How effect resolution looks (v0.2.3+)

    • When an effect resolves, its source card (and target) flashes briefly. Your input is never blocked.
    • While a chain is building and you are asked whether to respond, the left panel lists every stacked effect in order (CHAIN x2 / L1 … / L2 …).
    • A message interrupts only when your own effect is stopped:
      • EFFECT NEGATED — the opponent negated it.
      • EFFECT FIZZLED … no target — it fizzled because its target was gone.
      • Opponent effects never interrupt you (check the log below the board).

    Frame and background colors

    Color Meaning
    Green (frame) Has an available action
    Red (frame) Can attack
    Yellow (frame) Selectable candidate
    White (frame) Cursor position
    Blue (background) Charged (a monster that can act)
    Gray (background) Uncharged (already acted / cannot act)
    Green (attack number) Boosted by an effect (effective value for this battle)
