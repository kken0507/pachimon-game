    Settings

    Open SETTINGS from the Home screen. Move with Up/Down, change values with Left/Right, and run an item with Enter.

    Item Description
    Language Language (ja / en)
    Popup time Battle pop-up duration. MANUAL dismisses by key
    Board Log Bottom log mode (PLAY = narrated / RAW = raw)
    Buttons Controller button display (SPRITE = icons / KEYCAP = text)
    Theme Display theme (16-color palette; Left/Right = live preview, SAVE to apply)
    Fullscreen Fullscreen (ON / OFF; applied immediately; F11 also toggles)
    KEY CONFIG Key remapping. Reassign the key/button bound to each action
    SAVE Apply and remember (kept on next launch)
    DEFAULT Reset to defaults
    CANCEL Discard changes and go back (X / Esc also go back)

    !!! note "About language" The client UI supports ja / en. A language chosen in Settings is remembered on the next launch. To pick a language at startup, run e.g. pachimon --locale en.

    !!! note "About KEY CONFIG (remapping)" You can change the key/button bound to each action under KEY CONFIG. Select an action and confirm to enter capture mode, then press the single key/button to assign (cancel with BACK / Esc; it times out automatically). Use RESET to restore defaults. See Controls for details.
