    What's New

    Key changes per version. Get the latest from the public releases page.

    v0.2.3

    • You can now see effects resolve. Cards flash when an effect resolves, and while a chain is building, every stacked effect is listed in order in the left panel.
    • You are told when your effect is stopped — both when the opponent negates it and when it fizzles because its target is gone.
    • "REV" is shown while Revolution is active (attack/defence order reversed), next to the turn indicator.
    • New display theme AccessPoint (light beige + teal), selectable in Settings.
    • No rule changes — visuals only. Both the lightweight (RS engine) and standard builds show the same visuals.

    v0.2.2

    • The lightweight build (RS engine) now supports LAN play — play others on the same network, in addition to the AI (still small: ~16MB / ~31MB).
    • For internet (ROOM) online play, use the standard build.

    v0.2.1

    • Added a lightweight build (Rust engine) — about 1/3 the download size (Windows ~15MB / Linux ~30MB). AI only (use the standard build for online/LAN).
    • Slimmer builds by dropping unused bundled data; the standard build is a bit smaller too.

    v0.2.0

    Rule changes

    • Added a before-damage window in monster combat where boosts (e.g. K's King's Dignity) can activate — attacker first, then blocker, once each. → Battle & Attack Power
    • Fixed J's Revolution response timing and magic/trap chain resolution to match the canon.

    UI & controls

    • Boosted attack power shows the number in green; battles show effective values.
    • Shows material count for stacked (overlay-summoned) monsters (x2 / Mat x2).
    • The staircase activation menu now shows which hand cards it spends (Stair 3 (S3 S4 S5)).
    • Auto-fullscreen on first launch for handhelds like Steam Deck.

    Fixes

    • Display-mode switch failures no longer block startup (stays windowed).
